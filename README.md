# jogo-da-velha-7-vers-es

Projeto de Jogo da Velha (Tic-Tac-Toe) com 7 versões evoluídas, desenvolvido em HTML, CSS e JavaScript vanilla, sem bibliotecas ou frameworks.

## Versões

- **v1**: Tabuleiro 3x3, jogador vs. jogador, "X" começa, sorteio de quem fica com o "X"
- **v2**: Cadastro de nomes dos jogadores, placar de vitórias, botão para zerar placar
- **v3**: Símbolos personalizáveis (ex.: "A", "✌", emojis), sorteio de quem começa a partida
- **v4**: Modo jogador vs. jogador (PvP) e jogador vs. computador (PvC) com jogadas aleatórias
- **v5**: Dimensões do tabuleiro personalizáveis (linhas x colunas) e sequência vencedora configurável
- **v6**: Modo gravidade (Connect Four / Lig 4) — as peças caem até a posição mais baixa da coluna
- **v7**: Suporte a 2 ou mais jogadores, fundo universo Star Wars com estrelas animadas, linha vencedora destacada, emoji de comemoração por 2 segundos

## Como usar

Abra qualquer arquivo `index.html` dentro das pastas `v1` até `v7` no navegador.
